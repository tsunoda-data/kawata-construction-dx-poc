# Looker Studio ダッシュボード構築ガイド

本ドキュメントは、川田建設の「DXコックピット」ダッシュボードをLooker Studio（旧Google Data Studio）を用いて構築するための手順書です。BigQueryに格納されたデータを視覚化し、全社的な経営状況や各プロジェクトの原価、まちづくり事業のROI、キャッシュフローをリアルタイムでモニタリングする環境を構築します。

---

## 1. 前提条件

ダッシュボードの構築を開始する前に、以下の条件を満たしていることを確認してください。

- **Google アカウント**: Looker StudioとBigQueryにアクセス可能なGoogleアカウント。
- **BigQuery 環境**: 対象のGoogle Cloudプロジェクト内にデータセットが存在し、必要なテーブルおよびビュー（`vw_project_cost_summary`, `vw_cashflow_forecast`, `vw_area_roi`, `vw_company_dashboard` など）が作成済みであること。
- **Looker Studio へのアクセス**: [Looker Studio](https://lookerstudio.google.com/) にログイン可能であること。

---

## 2. BigQuery との接続手順

Looker StudioからBigQueryのデータソースに接続するための手順です。この作業は利用するすべてのテーブル/ビューに対して行います。

1. **Looker Studioへのログイン**
   [Looker Studio](https://lookerstudio.google.com/) にアクセスし、「空のレポート（Blank Report）」をクリックして新規レポートを作成します。

2. **データソースの追加**
   画面上に「データのレポートへの追加」ダイアログが表示されるので、Google コネクタの中から **「BigQuery」** を選択します。
   （※既存のレポートに追加する場合は、上部メニューの「データを追加」をクリックします。）

3. **プロジェクトとデータセットの選択**
   - **プロジェクト**: 今回利用しているGoogle Cloudプロジェクト名を選択します。
   - **データセット**: データが格納されているデータセット名を選択します。
   - **表（テーブル/ビュー）**: まずは `vw_company_dashboard` などのビューを選択し、右下の「追加」をクリックします。

4. **データ型の確認と設定**
   - 上部メニューの「リソース」→「追加済みのデータソースの管理」を開き、追加したデータソースの「編集」をクリックします。
   - 以下のデータ型が正しく認識されているか確認し、必要に応じて変更してください。
     - **日付フィールド**: データのタイプを「日付（YYYYMMDDなど）」に設定。
     - **金額フィールド（売上、原価など）**: データのタイプを「通貨」→「日本円（JPY - ¥）」に設定。
     - **パーセンテージ（利益率など）**: データのタイプを「数値」→「パーセント」に設定。
   - 設定が完了したら右上の「完了」をクリックします。

5. **その他のデータソースの追加**
   上記の手順を繰り返し、ダッシュボードに必要な他のビュー（`vw_project_cost_summary`, `vw_cashflow_forecast`, `vw_area_roi` など）を追加します。

## 3. ダッシュボードページ構成

DXコックピットは、用途に合わせて4つのページで構成します。レポート上部の「ページを追加」をクリックしてページを作成してください。

### ページ 1: 全社経営サマリー
経営層向けのトップレベルダッシュボードです。

- **データソース**: `vw_company_dashboard`, `vw_project_cost_summary`
- **カラースキーム**: ダークテーマ（ブルー/ティールのアクセント）

| チャート種類 | 指標 (Metrics) / ディメンション (Dimensions) | 設定詳細・目的 |
| :--- | :--- | :--- |
| **スコアカード** (4つ) | 全社売上、営業利益率、進行中工事数、手元資金 | 前年同期比の比較オプションを有効化。 |
| **円グラフ** | ディメンション: 事業部<br>指標: 売上 | 事業部別売上構成比を可視化。ドーナツ型を推奨。 |
| **時系列グラフ** | ディメンション: 月(Date)<br>指標: 売上 | 月別売上推移。実績と予測を別系列として表示。 |
| **表 (Table)** | ディメンション: 事業部<br>指標: 売上, 利益, 利益率, 進行中案件数 | 事業部別KPI一覧。利益率にはヒートマップ（条件付き書式）を適用。 |

### ページ 2: まちづくりROIダッシュボード
地域活性化と不動産・施設運営の相乗効果を測るダッシュボードです。

- **データソース**: `vw_area_roi`, `area_indicators`

| チャート種類 | 指標 (Metrics) / ディメンション (Dimensions) | 設定詳細・目的 |
| :--- | :--- | :--- |
| **棒グラフ (横)** | ディメンション: エリア<br>指標: ROI (%) | エリア別ROIの比較。またはGeoマップで地図上にバブル表示も可。 |
| **積み上げ棒グラフ** | ディメンション: エリア<br>指標: 収益 (内訳: 建設/不動産/施設) | エリア別収益構成。事業の多角化度合いを確認。 |
| **折れ線グラフ** | ディメンション: 年月<br>指標: 地価, 人口, 歩行者数 | エリア指標の推移。左右に2つのY軸を設けてスケールを調整。 |
| **表 / スコアカード**| ディメンション: エリア<br>指標: 投資総額, リターン総額 | エリア別の投資額とリターン一覧。 |

### ページ 3: 工事原価管理
プロジェクトマネージャー向けの原価・進捗管理ダッシュボードです。

- **データソース**: `vw_project_cost_summary`

| チャート種類 | 指標 (Metrics) / ディメンション (Dimensions) | 設定詳細・目的 |
| :--- | :--- | :--- |
| **表 (Table)** | ディメンション: 工事名, プロジェクトマネージャー<br>指標: 予算, 実績, 進捗率, 原価消化率 | 工事一覧。条件付き書式で「原価消化率 > 進捗率」の場合に行を赤くハイライト。 |
| **棒グラフ** | ディメンション: 原価カテゴリ<br>指標: 予算, 実績原価 | 予算 vs 実績原価の比較（ウォーターフォールチャート風の表現）。 |
| **ドーナツグラフ** | ディメンション: 原価カテゴリ（労務費, 材料費など）<br>指標: 実績原価 | 原価カテゴリ別構成比。 |
| **散布図** | X軸: 進捗率 (%)<br>Y軸: 原価消化率 (%)<br>ディメンション: プロジェクト名 | 案件の健全性可視化。Y > X となる赤字警戒ゾーンに背景色や参照線を設定。 |

### ページ 4: キャッシュフロー
財務・経理部門向けの資金繰り可視化ダッシュボードです。

- **データソース**: `vw_cashflow_forecast`

| チャート種類 | 指標 (Metrics) / ディメンション (Dimensions) | 設定詳細・目的 |
| :--- | :--- | :--- |
| **複合グラフ** | ディメンション: 月<br>指標: 入金(棒), 出金(棒), 累積残高(線) | キャッシュの増減と残高推移。 |
| **表 (Table)** | ディメンション: 月<br>指標: 期首残高, 入金, 出金, 期末残高 | 月別キャッシュフロー明細。 |
| **スコアカード** | 指標: 最小累積残高（将来Xヶ月） | 資金ショートリスク月のハイライト。残高が一定額を下回る場合にアラート色に変更。 |

## 4. デザインガイドライン

プロフェッショナルなポートフォリオとして見栄えを良くするため、以下のデザインルールを適用してください。

- **テーマ**: 上部メニュー「テーマとレイアウト」から「Constellation（ダーク）」などのダークテーマをベースにします。
- **カラーパレット (Hex Codes)**:
  - 背景色: `#121212` または `#1A1A1A`
  - パネル/カード背景: `#2C2C2C`
  - プライマリアクセント (Blue): `#1A73E8` (Google Blue)
  - セカンダリアクセント (Teal/Green): `#00BFA5` または `#0F9D58`
  - アラート (Red): `#D93025`
  - テキスト (白/グレー): `#FFFFFF`, `#BDBDBD`
- **フォント**: `Noto Sans CJK JP` または `Roboto` を統一して使用。
- **レイアウトグリッド**:
  - 画面幅は `1200px` または `1366px`（16:9比率）を推奨。
  - 各チャートやコントロールの間に `16px` ～ `24px` の余白（マージン）を均等に設ける。
- **フィルター配置**: ダッシュボードの最上部に横一列でコントロール（プルダウン等）を配置し、ヘッダー領域として視覚的に区切る。

## 5. インタラクティブ機能

ユーザーがデータを深掘りできるよう、以下の機能を追加します。

1. **コントロール（フィルター）の追加**
   - 上部メニュー「コントロールを追加」から以下のフィルターを最上部に設置します。
     - **期間設定**: 「期間コントロール」を追加（例：過去12ヶ月、今年など）。
     - **プルダウンリスト**: 「事業部」「エリア」「プロジェクトマネージャー」などのディメンションを指定。
2. **クロスフィルタリング**
   - 各チャートを選択し、右側のプロパティパネルで **「クロスフィルタリング」** を有効化します。これにより、円グラフの特定の事業部をクリックすると、ページ全体のデータがその事業部に絞り込まれるようになります。
3. **ドリルダウンナビゲーション**
   - テーブルのディメンションに「ドリルダウン」を有効化し、例えば「エリア」→「プロジェクト」の順で階層的にデータをドリルダウン表示できるようにします。

## 6. スクリーンショット撮影ガイド（GitHub掲載用）

作成したダッシュボードは、GitHubのREADMEやポートフォリオ（note等）で魅力的に見せるためにスクリーンショットを撮影します。

1. **撮影方法**
   - ダッシュボードの右上の「表示」ボタンをクリックし、閲覧モードにします。
   - ブラウザをフルスクリーン（または不要なツールバーを隠した状態）にします。
   - Macの場合は `Cmd + Shift + 4` で範囲指定するか、`Cmd + Shift + 3` で全画面撮影します。
2. **保存場所と命名規則**
   - 保存先: プロジェクト内の `assets/images/` などのディレクトリに保存します。
   - 命名規則: `dashboard_summary_dark.png`, `dashboard_cost_management.png` のように、内容がわかる英語名にします。
3. **README.md への埋め込み**
   - GitHubのREADMEには以下のようにMarkdownで記述して画像を埋め込みます。
   ```markdown
   ### 全社経営サマリー（DXコックピット）
   ![Company Summary Dashboard](./assets/images/dashboard_summary_dark.png)
   ```

## 7. 次のステップ

ダッシュボード構築後の運用・展開として、以下を検討してください。

- **定期メールレポートのスケジュール設定**
  Looker Studioの右上の「共有」の横の矢印から「レポートの配信をスケジュール」を選択し、毎週月曜日の朝に経営陣宛にPDFレポートが自動送信されるよう設定します。
- **Google サイトへの埋め込み**
  社内ポータル（Google Workspaceを利用している場合はGoogle Sites）に、「ファイル」→「レポートを埋め込む」で発行したiframeタグを用いてダッシュボードを埋め込み、全社員が容易にアクセスできる環境を構築します。
- **モバイル最適化**
  現場のスマートフォンから閲覧できるよう、「テーマとレイアウト」からモバイル向けに縦長の別ページを作成し、要素を大きく配置したモバイルレイアウト版を用意します。
